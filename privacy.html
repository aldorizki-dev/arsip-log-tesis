Kebijakan Privasi arsip-log-tesis

Terakhir diperbarui: 9 November 2026

Pengguna

arsip-log-tesis adalah alat pribadi yang hanya digunakan oleh pengembangnya sendiri. Aplikasi ini tidak melayani pengguna lain.

Data Google yang diakses

Aplikasi meminta izin https://www.googleapis.com/auth/drive.file, yang hanya memberi akses ke file dan folder yang dibuat oleh aplikasi ini di Google Drive pengguna. Aplikasi tidak dapat membaca file lain di Google Drive.

Penggunaan data

Aplikasi hanya membuat folder dan mengunggah salinan file log server ke Google Drive milik pengguna yang memberi izin. Tidak ada data Google pengguna yang dikirim, dijual, atau dibagikan kepada pihak ketiga.

Penyimpanan kredensial

Token akses disimpan hanya di server milik pengguna. Pengguna dapat mencabut akses kapan saja melalui https://myaccount.google.com/permissions.
